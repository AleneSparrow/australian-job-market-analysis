# Reports

This folder contains project reports, summaries, and final analytical
findings from the exploratory data analysis.

## Files

- **[project_summary.md](project_summary.md)** — final project summary:
  key findings, dashboard descriptions, data sources, and limitations.
  Start here for the high-level overview.

- **[key_findings.md](key_findings.md)** — the core list of insights
  discovered during analysis, with supporting numbers.

- **[eda_findings.md](eda_findings.md)** — full exploratory data analysis
  log for the overall market dataset (skills, employment type, visa
  sponsorship, experience level, salary coverage, top employers,
  geographic distribution, remote/hybrid/onsite).

- **[EDA_findings_it.md](EDA_findings_it.md)** — exploratory data analysis
  specific to the IT-segment subset.

- **[IT_segment_vs_Overall_market.md](IT_segment_vs_Overall_market.md)** —
  side-by-side comparison of the IT segment against the overall market
  across all key metrics, including the SQL queries used.

- **[collection_coverage_report.md](collection_coverage_report.md)** —
  coverage and completeness of the raw data collection across sources.

- **[raw_data_validation.md](raw_data_validation.md)** — data quality
  checks performed on the raw datasets (duplicates, missing values,
  salary coverage, top titles/companies/locations).

- **[job_title_classification_report.md](job_title_classification_report.md)** —
  methodology and results of classifying job titles into role families
  and seniority levels.

- **titles_for_manual_review.csv / titles_for_manual_review_completed...** —
  job titles flagged for manual review during classification, and the
  completed review.

See the main [README](../README.md) for project background and goals, and
[visualizations/](../visualizations/) for the Tableau workbook and
dashboard screenshots.
