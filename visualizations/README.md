# Visualizations

This folder contains the Tableau workbook, dashboard screenshots, and
supporting visual assets for the project.

## Files

- **Australian_IT_dashboard.twbx** — full interactive Tableau workbook.
  Open with Tableau Desktop or the free Tableau Reader.

- **Skills_on_map_dashboard.png** — Dashboard 1: top 20 in-demand IT
  skills, geographic distribution across Australian cities, and an
  interactive map of vacancy locations.

- **KPI_dashboard.png** — Dashboard 2: experience level breakdown, work
  format split (remote/hybrid/onsite), and key market KPIs (salary
  disclosure, visa sponsorship, total vacancies).

- **IT_vs_Market_summary_dashboard.png** — Dashboard 3: dumbbell chart
  comparing the IT segment vs. the overall market across six metrics, plus
  a Sankey flow of Employment Type → Experience Level → City.

See the main [README](../README.md) for project background and key
findings, and [reports/](../reports/) for the full analytical write-ups
behind each dashboard.
