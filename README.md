# Australian Job Market Analysis

## Project Overview

This project analyzes the Australian job market for data-related roles, including Data Analyst, Business Analyst, BI Analyst, and related positions.

The goal is to understand:

- Which data roles are most in demand
- Which technical skills employers require
- Where the most job opportunities are located
- What salary ranges are offered
- Which industries hire data professionals
- How requirements differ between junior, mid-level, and senior roles
